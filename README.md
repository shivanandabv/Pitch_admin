# PitchXPO Admin React Project

Vite + React admin dashboard based on the final PitchXPO design.

## Included
- Login page with Email, Password, Show/Hide Password, Remember Me and Forgot Password placeholder
- Logout returns to Login and protected session state
- Dashboard
- Applications: search, filter, add, edit, delete, approve/status editing, CSV/Excel-compatible export
- Payments: USD amounts, search/filter and export
- Events: Add/Edit/Delete with **From Date + To Date** validation
- Types & Pricing in USD
- Admin Users: add and activate/deactivate
- Browser localStorage persistence
- PitchXPO logo
- Responsive UI
